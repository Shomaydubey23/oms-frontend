# Office Management System

## Overview
A Full Stack Office Management System developed using React JS and Spring Boot.

## Features
- Employee Management
- Department Management
- Project Management
- Dashboard
- Authentication & Authorization
- CRUD Operations

## Tech Stack

### Frontend
- React JS
- Bootstrap
- JavaScript
- Axios

### Backend
- Spring Boot
- Java
- MySQL

## Installation

Frontend:

```bash
npm install
npm start
```

Backend:

```bash
mvn spring-boot:run
```
